# carpet-royale-server

Лобби и релей для интернет-игры **Carpet Royale** (WebSocket). Хранит список комнат
(имя, игроки, пинг хозяина) и пересылает пакеты Godot-мультиплеера внутри комнаты.

## Деплой на Render (без пароля и ключей)
1. Загрузите содержимое этой папки в репозиторий GitHub (`server.js`, `package.json`, `render.yaml`, `test.js`, `.gitignore`).
2. На render.com: **New → Blueprint** → выберите репозиторий → **Apply**. Тариф free.
3. Когда сервис запустится, откройте его адрес, например `https://carpet-royale-server.onrender.com/health` — должно быть `ok`.
4. В игре: **Мультиплеер → Интернет**, в поле «Сервер» впишите `wss://<ваш-адрес>.onrender.com`
   (если имя сервиса свободно, это `wss://carpet-royale-server.onrender.com` — адрес по умолчанию).

Бесплатный сервис Render засыпает после ~15 минут без трафика; первое подключение после сна занимает до минуты
(игра повторяет попытки сама).

## Локально
```
npm install
npm start      # слушает порт 8080 (или $PORT)
npm test       # проверка протокола
```
В игре укажите `ws://<IP компьютера>:8080`.

## Протокол
JSON-сообщения: `list`, `ping`, `create`, `join`, `state`, `kick`, `leave` (клиент) и `hello`, `rooms`, `pong`,
`created`, `joined`, `peer`, `gone`, `closed`, `error` (сервер). Бинарные пакеты: `[int32 кому][режим][канал][данные]`.
